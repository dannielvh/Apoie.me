# ❤️ Apoie.me

> Conectando pessoas, doações e voluntariado para fortalecer iniciativas sociais.

---

## 📖 Sobre o Projeto

O **Apoie.me** é uma plataforma web desenvolvida com o objetivo de aproximar a sociedade de instituições e centros de apoio que necessitam de doações e voluntários.

A plataforma centraliza informações sobre organizações sociais, suas necessidades e oportunidades de voluntariado, permitindo que usuários encontrem formas de contribuir de maneira simples, rápida e segura.

O sistema busca aumentar a visibilidade de projetos sociais, facilitar o processo de doação e incentivar a participação da comunidade em ações solidárias.

---

## 🎯 Objetivo

O Apoie.me tem como principal objetivo servir como uma ponte entre instituições sociais e pessoas interessadas em ajudar.

A plataforma permite:

* Divulgar centros de apoio e organizações sociais;
* Facilitar a realização de doações;
* Incentivar o voluntariado;
* Centralizar informações relevantes em um único local;
* Ampliar a visibilidade de projetos sociais.

---

## ✨ Funcionalidades

### 👤 Usuários

* Cadastro e autenticação de usuários;
* Visualização de instituições cadastradas;
* Consulta de necessidades das instituições;
* Registro de interesse para voluntariado;
* Acompanhamento de informações sobre campanhas.

### 🏢 Centros de Apoio

* Cadastro de instituições;
* Gerenciamento de informações da instituição;
* Cadastro de necessidades;
* Divulgação de oportunidades para voluntários;
* Atualização de dados de contato e localização.

### ❤️ Doações

* Consulta de itens necessários;
* Divulgação de formas de contribuição;
* Acompanhamento de necessidades das instituições.

## 🚀 Como Executar

### Clonar o Repositório

```bash
git clone https://github.com/SEU-USUARIO/apoie-me.git
```

### Entrar na Pasta do Projeto

```bash
cd apoie-me
```

### Instalar Dependências

Frontend:

```bash
npm install
```

Backend:

```bash
npm install
```

### Executar o Projeto

Frontend:

```bash
npm run dev
```

Backend:

```bash
npm start
```
