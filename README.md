# ❤️ Apoie.me

> Conectando pessoas, doações e voluntariado para fortalecer iniciativas sociais.

---

## 📖 Sobre o Projeto

O **Apoie.me** é uma plataforma web desenvolvida com o propósito de aproximar cidadãos, voluntários e instituições sociais, criando um ambiente centralizado para divulgação de necessidades, oportunidades de ajuda e informações relevantes sobre ações sociais.

O projeto surgiu durante a disciplina de Engenharia de Software, a partir da proposta de desenvolver uma solução completa que aplicasse conceitos de análise, projeto e desenvolvimento de sistemas. Durante o processo de idealização, a equipe discutiu desafios enfrentados por comunidades afetadas por tragédias e situações de vulnerabilidade social, como as ocorridas em Minas Gerais, percebendo a dificuldade que muitas pessoas encontram para descobrir onde e como ajudar.

Dessa reflexão nasceu o Apoie.me: uma plataforma que busca reduzir a distância entre quem deseja contribuir e as instituições que necessitam de apoio.

Atualmente, o sistema possui foco inicial no estado de Minas Gerais, permitindo que organizações sociais divulguem suas necessidades e encontrem pessoas interessadas em colaborar por meio de doações ou trabalho voluntário. Entretanto, a proposta foi concebida visando uma futura expansão para outras regiões do país.

Além de facilitar a conexão entre a população e as instituições, o Apoie.me busca promover a conscientização social, aumentando a visibilidade de projetos comunitários e incentivando a participação ativa da sociedade em ações solidárias.

O desenvolvimento do sistema também envolve a aplicação de conceitos fundamentais de Engenharia de Software, incluindo levantamento de requisitos, modelagem, prototipação, desenvolvimento incremental e utilização da metodologia Scrum, buscando construir uma solução organizada, segura, acessível e responsiva.

---

## 🎯 Objetivo

O principal objetivo do Apoie.me é servir como uma ponte entre instituições sociais e pessoas interessadas em contribuir para causas sociais, tornando o processo de ajuda mais simples, transparente e acessível.

A plataforma foi projetada para centralizar informações que normalmente se encontram dispersas em redes sociais, sites e diferentes canais de comunicação, facilitando a identificação de necessidades reais e oportunidades de colaboração.

Por meio do Apoie.me, busca-se:

* Aproximar cidadãos de instituições sociais;
* Facilitar a localização de organizações que necessitam de apoio;
* Incentivar a participação em ações de voluntariado;
* Divulgar necessidades reais de instituições e centros de apoio;
* Promover maior visibilidade para projetos sociais;
* Conscientizar a comunidade sobre demandas sociais existentes;
* Disponibilizar informações confiáveis e centralizadas em um único ambiente;
* Contribuir para o fortalecimento da solidariedade e da participação comunitária.

Mais do que uma plataforma tecnológica, o Apoie.me busca utilizar a tecnologia como ferramenta de transformação social, incentivando a construção de uma rede colaborativa entre instituições e sociedade.

---

## ✨ Funcionalidades

O Apoie.me foi projetado para oferecer uma experiência simples e intuitiva tanto para usuários interessados em ajudar quanto para instituições que necessitam de apoio.

A plataforma centraliza informações sobre organizações sociais, suas necessidades e oportunidades de participação, reduzindo barreiras de comunicação e facilitando o contato entre todas as partes envolvidas.

### 👤 Usuários
Os usuários cadastrados na plataforma podem:

* Criar e gerenciar sua conta;
* Realizar autenticação segura no sistema;
* Explorar instituições cadastradas;
* Consultar informações detalhadas sobre organizações sociais;
* Visualizar necessidades divulgadas pelas instituições;
* Demonstrar interesse em atividades de voluntariado;
* Acompanhar informações disponibilizadas pelas organizações;
* Encontrar formas de contribuição de maneira rápida e organizada.

### 🏢 Centros de Apoio

As instituições cadastradas possuem recursos para:

* Solicitar cadastro na plataforma;
* Manter informações institucionais atualizadas;
* Divulgar suas necessidades atuais;
* Informar oportunidades para voluntários;
* Disponibilizar meios de contato;
* Atualizar endereço e informações de localização;
* Aumentar sua visibilidade perante a comunidade;
* Facilitar a comunicação com potenciais apoiadores.

Para garantir maior confiabilidade e reduzir riscos de fraudes, o processo de entrada de novas instituições passa por validação administrativa antes da liberação do cadastro.

### ❤️ Doações

No contexto das doações, a plataforma permite:

* Divulgação de itens e recursos necessários;
* Consulta rápida às demandas das instituições;
* Organização das necessidades por instituição;
* Facilitação do processo de contribuição;
* Maior transparência sobre o que está sendo solicitado.

## 🚀 Como Executar

### Clonar o Repositório

```bash
git clone https://github.com/SEU-USUARIO/apoie-me.git
```

### Entrar na Pasta do Projeto

```bash
cd apoie-me
```

### Instalar Dependências

Frontend:

```bash
npm install
```

Backend:

```bash
npm install
```

### Executar o Projeto

Frontend:

```bash
npm run dev
```

Backend:

```bash
npm start
```
